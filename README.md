🎬 Movie Booking Website (Frontend)

A frontend-only Movie Booking Web Application built using React JS + Vite, focused on delivering a smooth, real-world movie ticket booking user experience. The project simulates the complete booking flow — from browsing movies to seat selection and payment confirmation — using modern UI practices.

🔗 GitHub Repo:
https://github.com/praveen-7050/Movie-Booking-web.git

📌 Project Scope

This project covers the UI and client-side logic only. No backend or database integration is included. The primary goal is to demonstrate frontend architecture, component design, routing, and state handling.

⚙️ Project Setup & Run
# Clone the repository
git clone https://github.com/praveen-7050/Movie-Booking-web.git

# Navigate into the project
cd Movie-Booking-web

# Install dependencies
npm install

# Start the development server
npm run dev


App will run on:
👉 http://localhost:5173/
